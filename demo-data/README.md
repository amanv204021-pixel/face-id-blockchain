# Demo fixtures (DEMO MODE ONLY)

All images here are **AI-generated synthetic images supplied by the project
author** — safe to display and index locally. `fixtures.json` describes the
local index the backend searches in demo mode.

- `query/authorized_test_subject.png` — the demo upload
- `index/*.jpg|png` — the "public index" (one near-duplicate copy of the
  subject + six distractors). Similarities are computed for real at runtime.

⚠ These simulate a search index for offline demos. They are never presented
as real web results, and demo mode is always labeled in the UI.
